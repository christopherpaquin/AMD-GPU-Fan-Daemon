## 2026-08-17 22:28
**Task:** Scaffold AMD-GPU-Fan-Daemon from scratch - a systemd daemon that reads GPU junction temp (amdgpu hwmon) and CPU PECI temp (nct6797 hwmon) and drives motherboard fan headers (pwm2/pwm4/pwm7) as max(cpu_curve, gpu_curve), closing the gap where case fans only ever responded to CPU heat on this machine's MSI Z390-A PRO board.
**Decision:** Python stdlib-only implementation (no runtime pip deps - sysfs I/O, .env parsing, and sd_notify all hand-rolled), root-privileged systemd unit hardened with ProtectSystem=strict + ReadWritePaths=/sys/class/hwmon (explicitly NOT ProtectKernelTunables=yes, which breaks pwm writes), ExecStopPost reverting every header to pwm*_enable=5 (hardware auto) on any stop/crash as the safety fallback. Dead-band + rate-limit gating in curve.py prevents fan-speed chatter. hwmon device paths resolved dynamically by `name` file match every run, never hardcoded, since hwmon numbers shift across reboots.
**Why:** GPU (AMD Radeon AI PRO R9700) hit 92C junction under load with case fans doing nothing about it since all 3 populated headers were BIOS-configured to track only PECI Agent 0 (CPU temp). Plan approved via EnterPlanMode this session after a Plan subagent worked through the control-loop/safety-mode design; full design rationale lives in that approved plan (not duplicated here). PWM_MIN=64 (~25% idle floor, never fully stop) chosen over silent spin-down per explicit user preference.
